# vap api文档

## 1. 功能介绍
    VAP是在数字娱乐和在线互动的时代，视觉效果的精美程度直接影响用户体验。运用特殊算法打造的强大动画粒子特效渲染组件。它不仅能够为应用程序提供令人惊叹的动画效果，更为用户创造了一种身临其境的视觉享受。同时支持 iOS,Android,Web 平台。
    
    竞品库地址：
    https://gitee.com/openharmony-tpc/openharmony_tpc_samples/tree/master/vap

### 4.2 测试普通动画 GeneralAnimation.cj 功能介绍

#### 4.2.1 主要功能
##### 4.2.1.1 播放 play
```
设计接口：vap.play(uri)
接口描述：当点击play按钮时，可以触发动画的播放，播放完毕自动关闭动画窗口;
页面效果：

```
##### 4.2.1.2 暂停 pause
```
设计接口：vap.pause()
接口描述：当点击pause按钮时，可以触发动画的暂停播放，窗口的动画会暂停播放(注意：目前该功能不稳定，有时可能会失效，需要自测确定问题);
页面效果：

```
##### 4.2.1.3 停止 stop
```
设计接口：vap.pause()
接口描述：当点击stop按钮时，可以触发动画的停止播放，窗口的动画会停止播放;
页面效果：

```

##### 4.2.1.4 设置视频对齐方式 setFitType
```
设计接口：vap.setFitType(fitType)
接口描述：视频对齐方式为下拉框，接口设置视频对齐方式（支持FIT_XY,FIT_CENTER,CENTER_CROP）;该接口需要再接口需要在play之前使用，
页面效果：

```

### 4.4 测试新监听   NewOn.cj 功能介绍（目前由于缺少onload事件，无法自动播放按钮，功能暂未测试）

##### 4.2.1.1 跳过 skip
```
设计接口：vap.stop()
接口描述：进入页面会自动播放动画，未播放完毕前可以点击skip按钮，直接停止动画的播放，并且出现返回按钮，点击返回，回到主页面;
         当动画播放完毕，不会出现skip按钮，直接出现返回按钮，点击返回按钮，可以直接返回到主页面

```
